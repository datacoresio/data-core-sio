# DATA CORE --- Hébergement & Gaming Cloud

> **Projet pédagogique réalisé dans le cadre du BTS SIO (Services
> Informatiques aux Organisations).**

## Présentation du projet

Data Core est une **entreprise pédagogique fictive** créée par des
étudiants en BTS SIO. Ce site web a été conçu dans un cadre scolaire
afin de présenter une entreprise informatique, son identité, ses
services et son offre de manière professionnelle.

**Data Core n'est pas présentée ici comme une entreprise commerciale
réellement constituée.** Les services, formules, tarifs et éléments de
présentation éventuellement affichés sur le site sont des éléments de
démonstration destinés au projet pédagogique, sauf indication contraire
explicite.

## Services présentés

Le site présente plusieurs catégories de services informatiques :

-   **Hébergement de serveurs** : solutions VPS, serveurs dédiés et
    cloud.
-   **Serveurs de jeux** : hébergement de serveurs pour des communautés
    de joueurs, notamment Minecraft et FiveM.
-   **Solutions professionnelles** : infrastructure, accompagnement et
    services informatiques pour les organisations.
-   **Cybercafé / Gaming Lounge** : concept d'espace de jeu et de
    rencontre autour du numérique.

Les contenus du site servent à illustrer la façon dont une entreprise de
services informatiques pourrait présenter ses offres à des clients.

## Objectifs pédagogiques

Ce projet permet notamment de travailler sur :

-   la création et la structuration d'un site web ;
-   la présentation d'une entreprise et de ses services ;
-   l'organisation des contenus et la navigation ;
-   la conception d'une interface adaptée à différents écrans ;
-   la sensibilisation aux aspects professionnels, juridiques et
    réglementaires d'un service numérique ;
-   le travail en équipe dans le cadre du BTS SIO.

## Technologies

Le site est construit à partir des technologies web utilisées dans les
fichiers du projet, notamment :

-   **HTML** pour la structure des pages ;
-   **CSS** pour la mise en forme et le responsive design ;
-   **JavaScript** pour les interactions côté navigateur.

## Lancer le site en local

1.  Téléchargez ou copiez les fichiers du site dans un même dossier.
2.  Ouvrez le fichier `index.html` avec un navigateur web récent.
3.  Pour publier le site, déployez les fichiers sur une plateforme
    d'hébergement adaptée, par exemple Netlify.

Si le projet utilise des images, polices ou autres ressources externes,
conservez la structure des dossiers et les chemins de fichiers
nécessaires.
